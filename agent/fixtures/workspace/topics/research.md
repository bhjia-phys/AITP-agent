# Research programme: directions, connections and agreed choices

This synthetic programme exists for tests. It has two research directions, a learning direction, a retained
method question, connections, seeds and agreed choices. Nothing here is a scientific claim.

## 1. Toy spectra from an iterated map

Can a toy iterated map produce the same spectrum on every run? Two toy questions use one demo library
([spectra map](spectra/README.md)); a fix in the library can matter to both.

| Topic | What it currently implies for the direction |
| --- | --- |
| [Self-consistent spectra](spectra/selfconsistent/research.md), with its [stability branch](spectra/selfconsistent/stability/research.md) | The toy map settles for two of the three test cases; the third is open. |
| [Continuation](spectra/continuation/research.md) | Reading real-axis values off a few samples is not yet reliable. |

## 2. Toy growth measures
