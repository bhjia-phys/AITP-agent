# AITP memory

## The research cycle

Recover the context from the main note, decide what the task settles, use the Skills it needs, keep outcomes
in their homes, and close with the warranted next move.

## Timing and recovery

Write when the work has produced a durable change. No durable change means no write; read-only requests stay
read-only.

## Close the task visibly

State what is now supported, where it is retained, and what the evidence warrants next.

## Independent process review

After a compaction, at handoff or before outside reliance, have the reviewer check the record against the log.
