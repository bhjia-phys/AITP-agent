# Shared knowledge collection

- Entries carry frontmatter: `kind`, `area`, `support`, `review`, and for papers `arxiv`, `version`,
  `reading_depth`, `close_reading`.
- Support may differ within a note: a section may state its own support, and paragraphs carry attribution
  labels such as `[Imported]` and `[Reconstructed]`.
- Only the researcher sets `reading_depth: researcher-read` or `review: confirmed`.
- Research results enter the index only as provisional pointer rows citing their note.
