# AITP 知识库

[English](README.md) | 中文

## 概述

按既有 AITP 设计浏览知识索引、原子条目、来源精读、学习故事和可选作者集合；保留原作者记录的支持依据、复核状态与阅读深度，不将它们合为一个完成标记。

## 配置与行为

该插件在[共享资料界面](../ui-aitp-materials/README.zh.md)注册知识索引、阅读页标题和维基式正文。列表先展示标题和简短说明，可筛选已加载条目的类型；集合入口、完整依据和审阅信息默认收起，待确认状态仍直接显示；正文沿用 Harness 的 Markdown 与数学排版。展开文章目录时读取当前正文实际渲染的标题，点击后跳到对应标题，重复标题也分别定位，不猜测来源锚点。空文章和没有分节标题的文章分别提示。Host 知识提供者解析已有索引和原文链接；来源仍由原文件拥有，不推测相邻目录就是科研归属。

研究成果指针和保存的研读草稿保持 provisional，不因进入知识库界面而成为已复核知识原子。知识内容可沿引用返回文献或代码，选源和提问使用正常 Harness 会话。

## 开发备注

该客户端通过按领域分派的 `aitp.materials.catalog.body`、`aitp.materials.reader.header` 和 `aitp.materials.reader.body` 提供知识展示，跨插件仅传递来源数据和回调。正文经共享 `aitp.materials.markdown` 工厂组合原生文档阅读器、受控本地图片读取和来源链接。原文模式、精确选区、实际相关资料、课题会话和返回行为仍由公共阅读器管理。文章目录只负责当前正文内定位，不保存为引用位置。定向测试覆盖待确认指针、依据／审阅／阅读覆盖的区分、重复标题导航及 Markdown 来源传递；共享测试覆盖库之间的选源、导航和生命周期。索引解析和来源读取属于 Host。

## 模型体验

浏览不增加模型上下文。研究者明确提问后，Host 根据所选来源交付实际片段并记录其来源。

#### KV 缓存影响

Host 负责请求组装和来源更新。

## 已知限制与后续工作

- 没有自动知识晋升或科研结论写回。需要写成知识原子的研究结果仍须经 AITP 所要求的人类决策和后续写入流程。
