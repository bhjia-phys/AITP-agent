# AITP 科研资料界面

[English](README.md) | 中文

## 概述

文献库、知识库和代码库各自提供入口，共享资料读取、选源、研读和普通 Harness 会话。浏览、勾选和准备问题均不自动调用模型；缺失连接和读取限制始终可见。

## 配置与行为

插件只挂载一个 `researchResources` Remote。Host 负责已授权目录、稳定来源身份、有界读取和领域投影；浏览器只传目录 ID、来源 ID 与定位，不输入任意路径，也不默认使用模拟数据。来源身份包含目录和来源两部分；同名文件、多页引用和多个选段分别保留。

普通文件夹浏览复用 Harness 原生 Workspace files，由实际会话的工作目录和文件权限控制。Research 不另建文件树，也不为浏览文件创建会话；会话外科研资料仍通过已有授权来源和原生文档阅读器打开。

科研后端提供 `researchMaterials` 能力时，资料列表显示折叠的“保存文件”，PDF 阅读器显示明确的“导入 PDF 副本”。两者选择真实项目和主记录，展示实际根目录、课题目录，并要求使用者填写包含文件名的相对路径。已有 PDF 继续保留原位，只有明确导入才复制。可选的用途链接写入所展示的主记录，项目根记录默认不勾选关联；界面不生成目录规范或知识条目分类。文件保存、主记录关联和当前文件读回分别报告结果。“检查文件”复用原阅读器的打开方式，即使保存到另一课题，也保留原问题和返回位置。目录识别同时支持 Host 登记和显式连接，存在多个匹配目录时不猜测。

结果未知时，保留原始请求和同一操作 ID；浏览器存储可用时，在同一标签页刷新后仍可恢复，但不会自动重试。结果确认后清除待确认的浏览器记录，文件变化和关联失败仍明确展示。这些有限恢复数据只表示浏览器中尚待确认的操作，不构成第二套科研资料库。关闭后端时撤下表单与位置读取能力，只读项目无法提交文件。

空结果区分课题未关联资料与索引不完整；部分发现不再显示确定的空库文案。“库内全部资料”扩大列表范围，同时保留当前课题、已选来源、提问草稿和返回位置；工具栏可随时恢复课题关联筛选。“独立阅读”才会明确切换提问范围。读取失败保留真实错误类别。索引范围集中为一条可展开状态，保留原始诊断；真实读取失败仍明确显示。列表省略重复的介绍文案。

资料列表保留在左侧主区，打开资料后在右侧原生文档侧栏查看详情。资料库导航列出来源集合；项目与课题树通过原生右侧栏“科研项目”查看，不在资料库左栏重复展示。Materials 状态按课题保存列表筛选、目录、滚动位置和来源集草稿；原生侧栏按库和课题分别保存文档标签，切换标签、库或课题时保留已挂载的阅读器。全局提问范围和课题范围明确分开，资料的维护归属不会替换当前提问课题。资料通过框架资源读取，通知只要求重新读取权威值，不维护第二份正文缓存。PDF 复用文档预览插件的完整连续阅读、选字、缩放、画布和 Worker；页码是从一开始的物理页，不能冒充核对过的印刷页码。Markdown 精确选段只取自原文文本视图。

链接中的 Markdown、图片与源码按实际格式在当前库旁的原生文档标签中打开，列表保留在原处。文档导航使用原生标签切换、关闭和收起；资料库的返回课题操作回到最初课题。原生 Markdown 只通过 Host 观察到的来源引用解析本地链接和插图；插图可使用原生放大查看，独立图片保留原生缩放与滚动位置。未支持或无法解析的本地链接不会改用会话文件权限读取。

“来源集与目录”通过已有 Harness 工作区 ID 建立只读连接，路径由 Host 确定。断开只撤销该连接；独立配置或科研授权可能继续保留读取。来源集保存于 Host 的操作存储，只保留引用、选中段落和明确课题关联；重新打开时重新核对标题与可用性，不改变当前问题范围，也不修改科研原文。未知保存结果保留原请求及操作 ID，显式检查重复同一次操作，不创建另一份来源集。

已安装的库会在 Research 拥有的课题材料扩展处贡献“相关库”按钮，打开当前课题明确关联的资料，并可返回原课题。卸载库只撤掉自己的按钮，原有材料链接仍可使用。有界的标签页存储保存待确认来源集操作；同标签页刷新后一律恢复为结果不确定，不自动提交，确认回执后清除。恢复记录无法读取或存储失败时明确显示。

恢复记录的写入和读取使用相同的格式检查、待确认操作数上限及编码字节预算，不另设资料数量上限；来源集可包含多少资料仍由 Host 配置决定。拒绝写入时保留原恢复记录，并明确提示新操作无法从标签页存储恢复。

科研讨论插件可用时，“讨论这份资料”“讨论这一页”和“讨论已选资料”在左侧主区显示当前方向或全局独立阅读的正常 Harness 会话，右侧文档仍可阅读。关闭讨论会返回保留原位的列表。没有明确选好的来源集时，打开的资料成为下一条消息的当前阅读上下文，但不会自动加入来源集草稿。翻阅 PDF 不改变已选来源；只有明确点击“讨论这一页”才附加该物理页。增删选源只准备下一条消息，不自动发送。重新打开来源集会同步更新显示的选源与下一条消息的资料，始终使用开始加载时的课题。延迟返回不能覆盖之后的新选源、来源集编辑或待确认的保存与提交；输入问题不会取消资料加载。研读快捷操作在同一个输入框准备可编辑的问题。正常提交保留请求 ID、队列或引导模式、附件及精确来源定位，统一通过已有研读接口进入当前会话。回答引用在原生文档侧栏打开相应资料，并保留返回课题的路径。

科研讨论插件不可用时，保留原有独立提问框，明确提交后打开普通 Harness 会话。显示资料或勾选来源不表示模型已读；实际交付的片段与恢复由科研记忆服务负责，可在“来源与记忆”查看。

公共列表负责搜索、资料目录筛选、加载与空内容状态以及来源集操作，通过按领域分派的 `aitp.materials.catalog.body` 插槽接入不同列表。公共阅读器提供 `aitp.materials.reader.header` 和 `aitp.materials.reader.body` 插槽，领域插件负责展示，PDF 页码、精确选段、讨论操作仍由公共层拥有。插槽只传观察到的数据和有限回调，不授予文件系统权限，也不互相导入插件组件。代码目录位置保留在已有的按课题划分的视图状态中。

全局代码总览先列出已配置的检出，选中后再读取当前一层目录，进入子目录时再读取下一层。课题内的总览只列出有实际记录关联的检出；浏览关联仓库时，所选课题仍是讨论范围。

后续页读取失败且没有保留的列表内容时，错误界面仍提供“第一页”。明确点击后只清除分页游标，保留搜索词和资料目录筛选；刷新不会静默丢弃当前页。

来源操作放在正文前；PDF 提取文本、原文位置与读取信息按需展开。尚未选择来源时不占用空白提问框，选中后显示已有提问流程；已填写的问题和待确认操作仍会保留。按钮、图标、字体及主题使用 Harness 原有组件与变量，在 390 CSS 像素宽度下换行展示。

阅读器的 `presentation: 'dock'` 模式填满原生侧栏，不再添加第二个文档标题或 PDF 翻页工具栏。所有阅读器上方都有简短的位置提示，显示来源目录和相对路径；展开后可见完整位置及研究记录中的用途，目录信息缺失时明确说明。PDF 和图片由原生阅读器管理缩放与滚动；物理页码仍用于准确的讨论与引文定位。Markdown 保留原文标题和原生 frontmatter 展示，并提供原文文本供精确选择。普通 Markdown 笔记即使来自代码目录，也不显示仓库控制栏。读取信息和相关链接收在正文下方的简短折叠区。源码和补丁复用 `document.code.reader`；真正的仓库视图仍通过受控接口查看修改和历史。某个库的界面插件关闭后，其他已启用的库仍可通过共享阅读器打开有权限的来源，保留原始身份与提问课题。

## 开发备注

共享状态由框架创建，独立库只贡献入口与本地化字段。测试覆盖真实 Remote 挂载、重载、独立卸载、跨目录同名来源、多个定位、提问范围、未知保存与 PDF 生命周期；真实 provider 和浏览器验证由[实施计划](../../../docs/agent/14-implementation-blueprint.md#native-source-readers)维护，与组件和注册测试分开报告。

PDF 通过原生文档阅读器的 `document.pdf.reader` 工厂连续展示，支持正文选字和缩放。完整文件由 `aitp-material-bytes` 在现有来源根授权和大小限制内读取；当前页文字作为单独的带定位来源观察读取。页码、缩放和滚动位置保留在对应课题范围，已经退出的阅读器回调不能覆盖新位置。引用必须来自同一物理页，并在该页当前文本中唯一匹配；排版引入的空白差异映射回实际原文。浏览不会改变已经选好的来源或发送问题。二进制服务未连接、权限不足或文件超限均明确显示；本次没有加入 OCR、PDF 编辑或批注保存。

Markdown 和图片通过原生文档插件的 `document.markdown.reader` 与 `document.image.reader` 根工厂展示。资料 owner 提供当前文本、已授权的图片字节和来源导航回调，负责本地图片订阅，并在阅读内容改变时释放 Blob URL。图片与 PDF 共用有界的 `aitp-material-bytes` 传输，SVG 始终使用原生静态图片元素。预览不产生 OCR 文本、图像区域引用或自动交给模型的图片输入。

## 模型体验

只有明确提问才把原问题、全局或课题范围及所选引用交给 Host。Host 创建正常会话并记录实际交付内容；单纯浏览不加入模型上下文。

#### KV 缓存影响

请求组装、来源更新和缓存前缀由 Host 科研记忆集成负责。

## 已知限制与后续工作

- 未保存问题和视图仅在当前客户端保留；可用的标签页存储会保存待确认操作以供同标签页刷新恢复，关闭标签页可能丢失这些恢复元数据。已保存来源集及操作回执由 Host 持久保存。
- 提问回执缺失不能证明没有创建会话，不会自动再次提交。
- 原文选择会拒绝重复或无法唯一定位的文字；富文本数学选区、Office 科研资料阅读、图像区域选择、OCR、批注保存与编辑仍未提供。
- 创建文件不会替换已有文件、自动更新知识索引、生成媒体或整理整个资料库；这些操作需要各自明确的工作流程。

研究课题中的资料可通过唯一明确归属于该工作区的授权目录，在同一原生侧栏中打开；读取权限和缺失、失败状态仍由来源服务确定。
