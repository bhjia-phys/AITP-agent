# AITP 代码库

[English](README.md) | 中文

## 概述

总览已连接的本地代码检出、分支、当前修订和改动路径数，打开代码或 Git 观察，再向选中的材料提问。

## 配置与行为

该插件在[共享资料界面](../ui-aitp-materials/README.zh.md)注册代码库入口。检出身份、读取限制、Git 状态与实际修订由 Host 提供者确定；浏览器不能授权任意路径或执行 Git 操作。同名文件在不同目录或检出中保持不同身份。

总览按代码库显示实际分支和本地修改数，进入后通过文件夹和面包屑逐级浏览，搜索直接列出匹配路径。文件夹从当前返回的资料页推导，因此仍遵循共享界面的部分结果提示和分页。按课题筛选时，即使结果不包含代码库总览记录，也能浏览关联文件。

阅读器通过原生 `document.code.reader` 工厂复用源码高亮、行号、复制与换行控件。Markdown 文件通过共享原生 Markdown 阅读器打开，支持已授权的本地图片和来源链接；原文模式保留文件文本。「源码、修改、历史」通过已有受控读取接口切换；修改显示真实工作区、暂存区或指定提交的补丁，Markdown 文件也保持补丁阅读方式，历史仅显示实际返回的提交并可查看对应版本。选择文件、引用文字和展开右侧研究对话时，保留来源身份、课题范围与返回位置。

代码定位保留实际行号与修订。状态和差异是读取时的观察，不表示当前会话造成了改动，也不构成科研计算验证。资料维护归属与当前提问范围保持独立。

## 开发备注

该客户端在共享资料插件声明的目录、阅读页头和阅读正文插槽中注册 `code` 呈现。领域测试覆盖文件夹边界、按课题筛选的代码库、实际补丁与历史定位以及异常观察的原文回退。传输、加载、来源选择、范围与生命周期仍由共享层负责；Git 与代码读取规则属于 Host 代码库插件。

## 模型体验

浏览不发送模型输入。明确问题携带选中的来源和定位，交给共享 Host 会话桥。

#### KV 缓存影响

Host 负责重新读取、请求组装和上下文更新。

## 已知限制与后续工作

- 不新增编辑器、调试器、执行权限或科研运行回执。既有 Harness 的编辑与执行保持原有权限；无法读取的检出和不完整历史明确显示。
