# AITP 文献库

[English](README.md) | 中文

## 概述

浏览已连接的本地 PDF、TeX 和文献记录，查看来源中明确记录的作者、年份、版本与阅读深度，并通过共享研读界面向选中的资料提问。

## 配置与行为

该插件在[共享资料界面](../ui-aitp-materials/README.zh.md)注册独立文献入口、馆藏列表与阅读页书目信息。列表区分标题、作者、年份和已有阅读覆盖，窄窗口将同样的信息排在标题下；阅读笔记与原文件分别标明。缺失字段显示“未记录”，打开文件不会自动变成已读。版本、阅读记录和文献元数据由 Host 文献提供者投影；没有依据时保留未知，文件名不能当作已核对书目信息。

PDF 用既有文档预览 Worker 绘制真实页，支持物理页导航和同页文本选择。文档声明的页标签、物理页和经核对的印刷页码含义不同。原文链接可返回相关知识记录或其他已连接资料；资料归属不会替换提问范围。

## 开发备注

插件通过按领域分派的 `aitp.materials.catalog.body` 与 `aitp.materials.reader.header` 贡献列表和标题信息。跨插件只传递来源数据与回调；选源、PDF、物理页位置、课题提问与返回仍由共享阅读器管理。定向测试检查缺失书目信息和整篇／片段选择的区分，共享组合测试检查三个领域入口以及独立卸载。书目和 PDF 读取规则属于 Host 文献插件。

## 模型体验

浏览文献不发送模型输入。明确提交的问题通过共享 Host 处理器交付所选来源与定位。

#### KV 缓存影响

实际来源交付和请求组装由 Host 负责。

## 已知限制与后续工作

- 不自动进行 OCR、图像区域精读或文献版本判断。缺失文件、部分索引和提供者限制按实际情况显示。
