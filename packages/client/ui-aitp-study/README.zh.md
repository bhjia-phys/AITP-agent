# AITP 研读笔记

[English](README.md) | 中文

## 概述

浏览、撰写、编辑和导出本地待核对笔记；明确保存真实完成的模型回答，并保留原会话、模型身份和当时来源。比较、综述、精读提纲、学习卡片与概念图先形成可编辑的问题，仍通过普通 Harness 会话完成。

## 配置与行为

独立插件只挂载 `researchStudy`，使用现有主面板和单侧栏。Host 管理操作存储及可选的只读来源桥，不启动第二套聊天系统；缺失服务或存储时显示不可用，不默认切换模拟数据。

资料选择下方的研读快捷项只填写可编辑任务，不调用模型。“写研读笔记”把引用记录为研究者手动关联，不宣称模型已读。保存回答只传当前真实完成消息的会话 ID 和事件序号，正文、模型、来源与当时上下文由 Host 恢复，客户端不能上传文本冒充模型回答。编辑后仍保留回答来源。人工关联、选中来源、已记录模型上下文和已记录来源读取分别显示。

所有产物均为待核对草稿。保存不会写入 `research.md` 或创建知识原子。Host 提供已保存草稿的来源引用，资料阅读器可将其再次显式选入问题。Markdown 导出包含保存正文和来源；移除草稿不删除原文或会话。

移除已保存产物只清除该产物对应的编辑草稿。无关的未完成笔记仍可通过“继续草稿”恢复。

保存、捕获回答或移除获得成功回执后，再次查看列表时从第一页重新读取，保留已选的类型筛选。旧分页游标属于操作前的列表版本，不能在此次修改后复用。

未知操作结果保留原请求和同一操作 ID；在显式检查确认前，界面锁定草稿修改，避免生成重复产物。

有界标签页记录保存待确认的保存、回答捕获和移除请求。同标签页刷新后恢复为结果不确定，保留原操作身份，不会自动重放；确认回执后清除。存储失败或无法读取的恢复记录明确显示，不替代 Host 中已保存的产物。

恢复记录的写入和读取使用相同的格式校验与 512 KiB UTF-8 字节预算，不另设引用条数上限。格式无效或超出预算的替换会保留原恢复记录，并提示新操作无法恢复。Host 对已保存产物的限制仍由其独立配置决定。

## 开发备注

声明和来源任务扩展均可随插件卸载撤回。测试区分手写内容、真实回答坐标、provisional 状态、引用依据、可编辑任务与未知操作恢复；真实提供者和浏览器验收见实施计划。

## 模型体验

只有普通 Harness 问题框提交准备好的任务。保存草稿可经 Host 来源桥用于新问题，但始终携带来源和待核对边界。浏览、准备任务和勾选来源均不等于已交付模型。

#### KV 缓存影响

Host 负责模型交付和请求组装，客户端不维护模型前缀。

## 已知限制与后续工作

- 未保存编辑仅在当前客户端加载期间保留；标签页存储可用时，待确认操作可在同标签页刷新后恢复，关闭标签页可能丢失恢复记录。已保存产物与确认回执由 Host 持久保存。
- 暂无跨客户端产物变更推送，另一客户端修改后需显式刷新。
- 快捷任务不生成音视频、渲染概念图、OCR 或自动知识晋升。
- 中断前缀或没有真实身份的模型消息不能保存为已完成回答。
