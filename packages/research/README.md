# Research

## Summary

This group connects scientific source files to Harness conversations. [Research memory](research-memory/README.md) owns scoped reads, existing-Session recovery and controlled scratch writeback. The [subsystem reference](../../docs/subsystems/research-memory.md) separates scientific sources, conversation evidence and rebuildable views. Browser transport lives in [ui-aitp-backend](../client/ui-aitp-backend/README.md).

[Shared resources](research-resources/README.md) owns local source authority and saved source sets. [Knowledge](research-knowledge/README.md), [literature](research-literature/README.md) and [code](research-code/README.md) supply independent projections. [Study](research-study/README.md) owns provisional notes and actual Session-answer capture; scientific conclusions remain in their existing notes.
