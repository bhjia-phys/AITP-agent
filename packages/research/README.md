# Research

## Summary

This group connects scientific source files to Harness conversations. [Research memory](research-memory/README.md) owns scoped reads, existing-Session recovery and controlled scratch writeback. The [subsystem reference](../../docs/subsystems/research-memory.md) separates scientific sources, conversation evidence and rebuildable views. Browser transport lives in [ui-aitp-backend](../client/ui-aitp-backend/README.md).
